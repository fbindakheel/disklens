# Changelog

All notable changes to the DiskLens project will be documented in this file.

## [1.0.0] - 2026-05-26

### Added
- **Parallel Scanning Worker**: Non-blocking Node.js `worker_threads` scanning.
- **Togglable D3 Visualizations**: Interactive D3-powered Treemaps, radial Sunbursts, and top-item Bar charts.
- **Virtualized Folder List**: High-performance `react-window` table listing.
- **Smart Cleanup Engine**: Automated filters for Xcode, node_modules, simulators, caches, and log files.
- **Duplicates Finder**: Size matching and content hashing duplicate detector with progress monitoring.
- **File Recency Heatmap**: Touch age categorizations.
- **History Snapshot Charts**: Storage growth timelines and comparison deltas.
