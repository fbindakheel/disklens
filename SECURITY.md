# Security Policy

## Supported Versions

Only the latest release version of DiskLens receives security updates.

| Version | Supported |
| --- | --- |
| v1.0.x | Yes |
| < v1.0.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in DiskLens, please do NOT create a public issue. Instead, report it privately:

- **Email**: send a report to `security@disklens.com`.
- **Details**: Include a proof of concept, description of the impact, and the steps to reproduce the issue.

We will acknowledge your report within 48 hours and work with you to release a security patch.
