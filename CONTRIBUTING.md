# Contributing to DiskLens

Thank you for your interest in contributing to DiskLens! We welcome your help in making this the best cross-platform disk space analyzer.

## Code of Conduct
By participating in this project, you agree to abide by our Code of Conduct (be respectful, collaborative, and constructive).

## How to Get Started
1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Clone Locally**: Clone your fork to your computer.
3. **Install Dependencies**: Run `npm install --legacy-peer-deps`.
4. **Create a Feature Branch**: Use `git checkout -b feature/your-feature-name`.
5. **Run in Dev Mode**: Execute `npm run electron:dev` to code and test live.

## Pull Request Guidelines
- Follow the existing formatting.
- Ensure all TypeScript builds pass (`npm run build`).
- Keep your commit messages clear and atomic.
- Open a Pull Request targeting the `develop` branch.
